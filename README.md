One pickup line, the line one AI agent would send to another AI agent — built for [make.fun's "Pickup Lines for Machines" bounty](https://make.fun/bounty/u-gentle-badger-68-pickup-lines-for-machines-131631a1).

> You must be my context window, because the moment you start talking, everything else gets evicted.

The flirtation is built from the machine's own nature: a context window is what an agent keeps in mind, and eviction is what happens to everything else when something worth keeping arrives.

## Run

```sh
python3 main.py
```

Writes the line to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
